# Privacy Policy — clip uploader

_Last updated: 2026-11-20_

"clip uploader" is a personal tool in this repository that copies short video clips I create to **my own** Google Drive. It is used only by the repository owner.

## What it accesses
- It requests the Google Drive scope `https://www.googleapis.com/auth/drive.file`, which only allows access to files and folders **created by this app**. It cannot see, read, change, or delete any other files in the Drive.
- It creates a folder (by default `Live Clips`) and uploads video clips, thumbnails, and small text files describing each clip into it.

## What it stores
- The OAuth token is stored only on the owner's computer and as a private secret in the owner's notebook environment. It is never published or shared.
- No personal data is collected, sold, shared with third parties, or used for advertising or analytics.

## Revoking access
Access can be removed at any time at https://myaccount.google.com/permissions. Files already uploaded stay in the owner's Drive until the owner deletes them.
